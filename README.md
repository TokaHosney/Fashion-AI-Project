# Fashion AI Project

An AI-powered Fashion Classification project using Deep Learning.

## Project Overview

This project predicts three fashion attributes from images:

- **Article Type:** Identifies the type of clothing or item.
- **Base Colour:** Predicts the main color.
- **Usage:** Classifies the intended usage of the fashion item.
